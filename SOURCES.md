### Library lending microservices

The source contains five standalone Maven applications: AuthServices, book, borrow, Gateway, and serviceRegistry. The three domain services use Java 17, Spring Boot, Spring Data JPA, and MySQL. Gateway uses Spring Cloud routing with Eureka, and borrowing calls member/book APIs with OpenFeign through a fixed gateway URL. There is no event broker in this repository.
